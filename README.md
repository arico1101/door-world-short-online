**トビラのマスはすべて `stop:true`。** サイコロで飛びこされると出会うトビラが3〜6枚とぶれて、1人プレイのネタバラシが薄くなるため、全員が必ず6枚全部と出会う（テストで担保）。増える手番は1人あたり1〜2回。

副作用として、**トビラのあいだにある おしごと・しゅっぴ・まなび のマスは飛びこされやすくなっている**（トビラからトビラへ跳ぶ形になるため）。下の「マスはすべてOK待ち」の実測はこれが理由。

### マスはすべてOK待ち（本番版と同じ）

**一度は「自動送り」にしたが、2026-09-10 に本人の指示でやめた。** 理由は、止まらずに流れるマスがわかりにくいこと。
いまは本番版と同じで、おしごと・しゅっぴも含めて**すべてのマスでモーダルが出て、OKを押すと次の番に進む**（`setInfo`）。

- **元に戻したのは `setFlash` とトースト表示**（`#toast` in `public/index.html`、`renderFlash()` in `public/app.js`、
  `g.flash` の状態）。まるごと削除したので、この点は本番版と差分ゼロになった
- **最初のおしごとのモーダルだけは中身が厚い。** かせぎの式と「同じはたらきでも生まれた場所で基本給がちがう」は
  学びの核なので、1回はじっくり見せる（`p.wageShown`）。2回目からは金額と、災害・返済の注記だけ

**戻すコストは小さい。** 4人1ゲームのOKタップ数を6ゲームずつ計測すると **46.8回 → 50.0回（＋3回ほど）**。
トビラを全部 `stop:true` にした結果、おしごと・しゅっぴのマスはもともと飛びこされることが多く、
自動送りはほとんど効いていなかった。25分の見積りへの影響はない。

盤面から落ちた本番版のトビラ：**学びなおし・挑戦・大きな夢**（いずれも26歳以降）。
`choiceDef()` の定義そのものは残してある（本番版との差分を小さく保つため）。

### AAI（あしながのアフリカ留学奨学金）を 26歳 → 19歳 に前倒し／扉を「大学のトビラ」に

**いちばん見落としやすい落とし穴。** AAIの選択肢は19歳の「大学のトビラ」(`key:"kaigai"`)の中にあり、本番版では26歳の「留学のトビラ」だった。
25歳で終わらせると、そのままでは盤面から消える。しかもAAIの扉は「遺児家庭（`perk` が `shienPro` か `deai`）のプレイヤーにしか存在しない扉」で、あしながの事業そのものを表す、この教材でいちばん大事な一枚。

**19歳に置いた理由**（実際のAAIの応募資格・2026-09に確認）：

- 応募できるのは**中等教育を卒業し、国家試験の結果を受け取ってから2年以内**の人
- **年齢上限はおよそ22歳**（年度により生年月日カットオフあり）
- 中等教育の最後の2〜3年で**クラス上位10%**が条件。合格後、約1年の準備プログラムを経て大学へ
- ウガンダの中等教育修了（S6）は7-4-2制でおよそ18〜19歳

つまり典型的な応募は卒業直後の18〜20歳。ゲームでは典型に合わせて19歳に置いた。

あわせて2点：

- **大学のマスに `stop:true` を付けた。** サイコロで飛びこされると、いちばん大事な扉が盤面から消えてしまうため
- **AAIのカギを ★5 → ★3 に下げた。** 19歳時点で★5はほぼ届かず、常に🔒の扉になってしまう。
  遺児家庭は12歳のまなび・15歳の進学を通ると19歳で必ず★3以上になるので、★3なら必ず開く（テストで担保）

さらに、**「自分の国の大学に進む」を足した**（カギ おかね150万＋★3／−150万・まなび+2・♥+2・`unlock`）。ウガンダにもマケレレ大学のような国立大学があり、壁は「知らないこと」ではなく**学費**だから、`tag` を付けず全員に見せてお金のカギだけで差がつくようにしている。`unlock:true` なので、国内の大学でも まなびがかせぎになる場（★×10万）につながる。

これで扉の名前を「留学のトビラ」→「**大学のトビラ**」に、盤面のマス名も「留学」→「**大学**」に変えた（15歳の「進学」＝中等教育と区別がつく）。

#### 150万という数字の根拠（通しプレイ360人ぶんの実測）

19歳の大学のトビラに立った時点の所持金を、家庭カード別に測った結果：

| 家庭 | 中央値 | 120万以上 | **150万以上** | 180万以上 |
| --- | --- | --- | --- | --- |
| 欧米 | 145万 | 69% | **49%** | 37% |
| 日本 | 180万 | 64% | **53%** | 51% |
| 駐在（ウガンダ） | 135万 | 58% | **44%** | 37% |
| ウガンダ・両親あり | 110万 | 40% | **21%** | 15% |
| ウガンダ・遺児（支援あり） | 60万 | 14% | **3%** | 0% |
| ウガンダ・遺児（支援なし） | 90万 | 32% | **10%** | 2% |

ウガンダ3家庭をまとめると **120万で28% → 150万で11%**。現実のウガンダの高等教育進学率は4〜5%で、120万は明らかに高すぎた。11%はまだ現実より高いが、**そこまで厳密に合わせなくてよい**という判断（2026-09-10）で 150万に確定。このゲームはもともと収入差なども「いっしょに遊べるように」ゆるめてある。

**もし将来もっと絞るなら、扉ごと作りなおすことになる。** 150万＋★3が、この扉の構造を壊さずに絞れる限界だから：★のカギを上げれば下がる（150万＋★5でウガンダ3%）が、この選択肢は「海外の大学」(150万＋★4)より**必ず軽く**しておかないと、海外に完全に見劣りして存在意義がなくなる。おかねを180万にすればウガンダ5%になるが、こんどは海外留学より国内のほうが高いという逆転が起きる。どちらを直すにも、海外の大学の数字（本番版から引き継いだ150万＋★4）を一緒に上げる必要がある。

### 24歳のしごとのトビラに「大学院」を追加（ショート版だけの選択肢）

19歳で**大学まで行けた人にだけ**開く選択肢。カギは `req:{univ:true, learn:6}`、効果は おかね−50万・まなび+3・♥+3。

「大学に行けた」と見なすのは、19歳の大学のトビラで **AAI**／**海外の大学に留学する**／**自分の国の大学に進む** のどれかを選んだとき（3つとも `univ:true` が付いていて、選ぶと `p.univ` が立つ）。

**？？？（見えない）ではなく🔒（カギ不足）で全員に見せている。** 「知らなかった」のではなく「19歳の選択が24歳の選択肢を決めていた」ことを見せるため。カギ表示は「大学を出ていること ＋ まなび ★6（大学に行っていない…）」となり、★が足りないと取りちがえないように理由を書きわけている。このカギだけは、24歳の時点ではもう取りに行けない。

### 人数：2〜6人 → 1〜4人

- ロビーの開始条件 `players.length >= 1`、上限4
- 1人プレイでは結果発表の「見くらべ」が成立しないので、**ネタバラシとトビラ一覧が主役**になるよう、
  ふりかえりの文言と `endingText(p, solo)` を1人用に切り替えている

### 奨学金は、25歳では返し終わらない

本番版は総額48万を1回6万ずつ、ゴール（35歳）で残額を一括清算する。
短縮版では**清算しない**（本人の指示・2026-09-09）。現実でも25歳で返済は終わらない。

- ゴールでの一括清算（`confirmPending` の `p.money -= p.loan`）を削除
- かわりにゴール画面と結果発表に「🎓 奨学金がまだ◯◯万のこっている」と出す
- 総額48万・1回6万の数字は変えていない

### そのほか

- エンディング `ENDINGS` を「25歳のいま」に書きかえ（2026-09-10 に本人が確定）
- 重いライフイベントのしきいを `p.pos >= 8` → `>= 6` に。できごとマスが3つしかなく、8のままだと1回しか起こりえないため
- 家庭カードの初期おかね・基本給・仕送りは**本番版のまま**。生まれた場所による差は薄めていない
