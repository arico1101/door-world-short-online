教育ボードゲーム「トビラ せかい版」オンライン版の、**あしなが内部での検証（デバッグ）用の短縮バージョン**。

中身を確かめたい人が、短い時間で一周まわして、結果発表とネタバラシまでたどり着けることが目的。
**学びの核（家庭カードの秘密、見えない選択肢、結果発表での種明かし）は削っていない。** 削ったのは長さだけ。

## 本番版から変えたところ

### 盤面：36マス → 24マス（6歳〜25歳）

**トビラのマスはすべて `stop:true`。** サイコロで飛びこされると出会うトビラが3〜6枚とぶれて、1人プレイのネタバラシが薄くなるため、全員が必ず6枚全部と出会う（テストで担保）。増える手番は1人あたり1〜2回で、次の「事務マスの自動送り」で相殺している。

### おしごと・しゅっぴのマスは、OK待ちにしない（自動送り）

25分に収めるためのショート版だけの仕組み。おしごと・しゅっぴに止まったときはモーダルを出さず、効果を反映してすぐ次の番へ進み、画面下に6秒のトーストで結果を流す（`setFlash` in `src/index.js`）。これで1ゲームあたり約30回のOKタップが消える。

- **最初のおしごとだけはモーダルのまま。** かせぎの式と「同じはたらきでも生まれた場所で基本給がちがう」は学びの核なので、1回はじっくり見せる（`p.wageShown`）
- 8歳の「はじめてのお手伝い」も子ども時代の一拍としてモーダルのまま
- 災害の影響・奨学金の返済など毎回変わる情報は、トーストにも必ず出す

盤面から落ちた本番版のトビラ：**学びなおし・挑戦・大きな夢**（いずれも26歳以降）。
`choiceDef()` の定義そのものは残してある（本番版との差分を小さく保つため）。

### AAI（あしながのアフリカ留学奨学金）を 26歳 → 19歳 に前倒し／扉を「大学のトビラ」に

**いちばん見落としやすい落とし穴。** AAIの選択肢は19歳の「大学のトビラ」(`key:"kaigai"`)の中にあり、本番版では26歳の「留学のトビラ」だった。
25歳で終わらせると、そのままでは盤面から消える。しかもAAIの扉は「遺児家庭（`perk` が `shienPro` か `deai`）のプレイヤーにしか存在しない扉」で、あしながの事業そのものを表す、この教材でいちばん大事な一枚。

**19歳に置いた理由**（実際のAAIの応募資格・2026-09に確認）：

- 応募できるのは**中等教育を卒業し、国家試験の結果を受け取ってから2年以内**の人
- **年齢上限はおよそ22歳**（年度により生年月日カットオフあり）
- 中等教育の最後の2〜3年で**クラス上位10%**が条件。合格後、約1年の準備プログラムを経て大学へ
- ウガンダの中等教育修了（S6）は7-4-2制でおよそ18〜19歳

つまり典型的な応募は卒業直後の18〜20歳。ゲームでは典型に合わせて19歳に置いた。

あわせて2点：

- **大学のマスに `stop:true` を付けた。** サイコロで飛びこされると、いちばん大事な扉が盤面から消えてしまうため
- **AAIのカギを ★5 → ★3 に下げた。** 19歳時点で★5はほぼ届かず、常に🔒の扉になってしまう。
  遺児家庭は12歳のまなび・15歳の進学を通ると19歳で必ず★3以上になるので、★3なら必ず開く（テストで担保）

さらに、**「自分の国の大学に進む」を足した**（カギ おかね120万＋★3／−120万・まなび+2・♥+2・`unlock`）。ウガンダにもマケレレ大学のような国立大学があり、壁は「知らないこと」ではなく**学費**だから、`tag` を付けず全員に見せてお金のカギだけで差がつくようにしている。`unlock:true` なので、国内の大学でも まなびがかせぎになる場（★×10万）につながる。

これで扉の名前を「留学のトビラ」→「**大学のトビラ**」に、盤面のマス名も「留学」→「**大学**」に変えた（15歳の「進学」＝中等教育と区別がつく）。

通しプレイでの実測（各家庭 8〜12人ぶん）では、120万のカギに手が届いた割合は **欧米 8/10・駐在 4/8・日本 4/10** に対し **ウガンダ両親あり 3/12・支援と出会えた遺児 0/9・出会えていない遺児 4/11**。遺児家庭にとっては AAI が現実的な唯一の道、という構図になっている（w6 が届くのは、15歳で進学せずに働いて貯めた場合）。

### 24歳のしごとのトビラに「大学院」を追加（ショート版だけの選択肢）

19歳で**大学まで行けた人にだけ**開く選択肢。カギは `req:{univ:true, learn:6}`、効果は おかね−50万・まなび+3・♥+3。

「大学に行けた」と見なすのは、19歳の大学のトビラで **AAI**／**海外の大学に留学する**／**自分の国の大学に進む** のどれかを選んだとき（3つとも `univ:true` が付いていて、選ぶと `p.univ` が立つ）。

**？？？（見えない）ではなく🔒（カギ不足）で全員に見せている。** 「知らなかった」のではなく「19歳の選択が24歳の選択肢を決めていた」ことを見せるため。カギ表示は「大学を出ていること ＋ まなび ★6（大学に行っていない…）」となり、★が足りないと取りちがえないように理由を書きわけている。このカギだけは、24歳の時点ではもう取りに行けない。

### 人数：2〜6人 → 1〜4人

- ロビーの開始条件 `players.length >= 1`、上限4
- 1人プレイでは結果発表の「見くらべ」が成立しないので、**ネタバラシとトビラ一覧が主役**になるよう、
  ふりかえりの文言と `endingText(p, solo)` を1人用に切り替えている

### 奨学金は、25歳では返し終わらない

本番版は総額48万を1回6万ずつ、ゴール（35歳）で残額を一括清算する。
短縮版では**清算しない**（本人の指示・2026-09-09）。現実でも25歳で返済は終わらない。

- ゴールでの一括清算（`confirmPending` の `p.money -= p.loan`）を削除
- かわりにゴール画面と結果発表に「🎓 奨学金がまだ◯◯万のこっている」と出す
- 総額48万・1回6万の数字は変えていない

### そのほか

- エンディング `ENDINGS` を「25歳のいま」に書きかえ（**下の「未決定」参照。監修が必要**）
- 重いライフイベントのしきいを `p.pos >= 8` → `>= 6` に。できごとマスが3つしかなく、8のままだと1回しか起こりえないため
- 家庭カードの初期おかね・基本給・仕送りは**本番版のまま**。生まれた場所による差は薄めていない

## 守るべき条件

1. **ウガンダで生まれた遺児家庭（w5/w6）が必ずゲームに入る。** 何人で遊んでも1枚は配られ、1人プレイならその1人が必ず w5 か w6。`deal()` のロジックと `test/short.mjs` で担保
2. **AAIのトビラを盤面から落とさない**（上記）
3. **秘密を削らない。** 家庭カードは本人の接続にだけ／選択肢とその状態も手番の人にだけ／`pnote`・`pnotes` は本人だけ／👁？？？の種明かしは結果発表まで伏せる
4. **新しいテキストは必ず日英そろえる**（`{ja, en}` ＋ `L()`）
5. **デザインは本番版のまま**（Zen Maru Gothic ／ クリーム `#FBF8F1` ＋ 茶 `#4A3A30` ／ 手描き風）

## ファイル構成

Cloudflare Workers + Durable Objects（無料枠）。

| ファイル | 役割 |
| --- | --- |
| `src/index.js` | Worker + Room（Durable Object）。ゲーム進行の全判定 |
| `public/rules.js` | サーバーと画面が共有するルール・文言・盤面データ |
| `public/app.js` | クライアント（表示と入力のみ） |
| `public/index.html` | 画面の骨格とCSS |
| `test/play.mjs` | 通しプレイの自動テスト（人数を変えて流す） |
| `test/ops.mjs` | 進行役むけ操作と、選択肢の秘匿のテスト |
| `test/short.mjs` | **ショート版だけのテスト**（下記） |
| `wrangler.toml` | Durable Object は SQLite バックエンド（無料枠の条件） |

## テスト

`npx wrangler dev` を起動したうえで：

```bash
for n in 1 2 3 4; do N=$n node test/play.mjs; done
node test/ops.mjs
node test/short.mjs
```

`test/short.mjs` が見ているのは、短くしたときに壊れやすい4つ：

1. ウガンダの遺児家庭(w5/w6)が、1〜4人すべてで必ず配られる（各人数40回）
2. 1人プレイで、ロビーからゴール・結果発表まで完走する
3. AAIのトビラが遺児家庭の19歳に必ず出る／カギ★3に届く（🔒のままなら失敗する）
4. 25歳のゴールで奨学金の残額が没収されず、結果発表に残る
5. 全プレイヤーが6枚のトビラ（進学・くらし・大学・まち・技術・しごと）全部と出会う
6. 24歳の大学院が、大学に行けた人にだけ開く（行けなかった人には🔒で見え、？？？にはならない）

## まだ決まっていないこと（あしなが側の判断が要る）

1. **「25歳のいま」のエンディング文言**（`ENDINGS` in `public/rules.js`）。
   いまはたたき台。ゲームの読後感そのものなので、**このまま本番に出さず監修を受けること**
2. **重いライフイベント（死別・干ばつ）の既定値。** いまはロビーのチェックボックスOFF（本番版と同じ）。
   検証用にONを既定にするかは未決定
3. **ウガンダの遺児家庭は「必ず1人」でよいか、「全員」にするか。** いまは「必ず1人」。
   生まれた場所による差を見くらべることが核なので、全員同じにすると比較が消える
3b. **国内大学のカギ（おかね120万）が妥当か。** 上の実測のとおり、欧米・駐在は8割前後、
   ウガンダ家庭は2〜3割で通る。ここを下げるとウガンダ家庭も大学に行きやすくなり、
   上げると「お金さえあれば」の構図が強くなる。生まれた場所による差の効き方を
   決める数字なので、通しプレイを見ながら調整すること。
   なお15歳の進学のトビラは中等教育のつもりなので `univ` には数えていない
   （数えると、遺児家庭こそ所得制限で必ず通る奨学金があるため、大学院のカギが実質消える）
4. **25分に収まるか。** 25分は**ふりかえり抜き・ゲーム部分だけ**の枠（本人の指示・2026-09-09）。
   カード確認3分＋プレイ（4人・約45手番）で、1手番25秒なら21分に収まる見積り。
   トビラ全stop化で増えた手番は、事務マスの自動送りで相殺している。
   **机上の計算なので、実際に人が読む速さで一度通してストップウォッチで測ること。**
   それでも長ければ、次は序盤の1マスずつ進む区間（`roll()` の `p.pos < 4`）を短くするのが効く
